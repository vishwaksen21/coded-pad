# Accessibility (a11y) Audit & Standards

Coded Pad complies with **WCAG 2.1 AA** accessibility standards:
- **Contrast**: Minimum 4.5:1 contrast ratio across both light and dark themes.
- **Screen Readers**: `aria-live="polite"` attributes announce dynamic save status changes.
- **Keyboard Navigation**: All interactive elements feature high-contrast visible focus rings (`:focus-visible`).
- **Touch Targets**: Minimum 44x44px touch targets on mobile viewports.
